# CONTRIBUTING

## PR-käytäntö
1) Avaa Issue mallista **Agent Task**.
2) Lisää label **agent:task**.
3) Odota agentin (Sweep) PR:ää, tarkista muutokset, tee kommentit ja mergeä kun CI on vihreä.

## Koodistandardi (tiivis)
- Backend: FastAPI, Pydantic v2.
- Tyylit: must/ruff (valinnainen).
- Älä commitoi `.env`-tiedostoa.
